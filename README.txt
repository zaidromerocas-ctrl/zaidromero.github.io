Publicación recomendada: GitHub Pages
1. Crea un repositorio público (por ejemplo: zaidromero.github.io).
2. Sube TODOS los archivos y carpetas de este paquete a la raíz del repositorio.
3. En Settings > Pages selecciona Deploy from a branch y la rama main, carpeta /root.
4. GitHub generará la URL pública del sitio.

IMPORTANTE:
- El sitio no publica archivos DWG/STL fuente.
- Los CV descargables son versiones PDF para postulación.
- Sustituye cualquier dato de contacto únicamente si deseas cambiarlo antes de publicar.
